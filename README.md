# EASYMCP — ChatGPT Connector for Shopify

Connect ChatGPT to your Shopify store. Describe any change — it goes live in seconds.

## What it does

- Edit themes, layouts and colours in plain language
- Create landing pages and blog posts
- Rewrite product descriptions in bulk
- Update navigation, banners and collections

No code. No developer. No drag-and-drop.
